# موقع محمد عماد — دليل الاستخدام

موقع شخصي لعرض أعمالك كمصمّم ومطوّر مواقع. الموقع باللغتين (العربية والإنجليزية) ويعمل بدون أي برامج أو خطوات بناء معقدة. كل ما ستحتاج إلى تعديله موجود في **ملفات بيانات بسيطة**.

---

## ١. خريطة الملفات

```
mo-emad-portfolio/
├── index.html            ← الصفحة الرئيسية (لا تحتاج تعديلها)
```

## ٢. قبل ما ترسل الموقع لأي عميل (مهم جدًا)

افتح الملفات دي واملأ الأماكن الفارغة أو المكتوبة بين [أقواس مربعة]:

| الملف | ماذا تعدّل |
|---|---|

## ٣. إضافة مشروع جديد (خطوة بخطوة)

**الخطوة ١:** افتح `data/projects.js`.

**الخطوة ٢:** الصق هذا القالب **بعد** السطر `window.PROJECTS = [` مباشرةً (أول مشروع في القائمة يظهر أولًا في الموقع):

```js
  {
    slug: "client-name",
    name: "Client Name",
    url: "https://client-website.com",
    year: "2026",
    color: "#2E5BFF",

    type: { ar: "موقع شركة", en: "Business website" },
    summary: {
      ar: "وصف قصير للمشروع في سطر واحد.",
      en: "A short one-line description of the project."
    },

    idea: {
      ar: "فكرة المشروع في جملتين أو ثلاث.",
      en: "The idea behind the project in two or three sentences."
    },
    brief: {
      ar: "ما الذي طلبه العميل؟",
      en: "What did the client ask for?"
    },
    built: {
      ar: ["ميزة ١", "ميزة ٢", "ميزة ٣"],
      en: ["Feature 1", "Feature 2", "Feature 3"]
    },

    cover: "assets/projects/client-name/cover.jpg",
    screenshots: [
      "assets/projects/client-name/shot-1.jpg",
      "assets/projects/client-name/shot-2.jpg",
      "assets/projects/client-name/shot-3.jpg"
    ]
  },
```

> لاحظ الفاصلة `,` في آخر القالب بعد `}`. هي التي تفصل المشروع عن المشروع اللي بعده.

**الخطوة ٣:** عدّل القيم:

- `slug`: اسم قصير **بالإنجليزي، حروف صغيرة، بدون مسافات** (استخدم `-` بدل المسافة). يُستخدم في رابط الصفحة وفي اسم مجلد الصور.
- `name`: اسم المشروع كما سيظهر.
- `url`: رابط الموقع الحقيقي. لو تركته `""` يختفي زر "زيارة الموقع".
- `year`: اختياري. اتركه `""` لو لا تريد إظهاره.
- `color`: لون الخلفية المؤقتة فقط قبل إضافة الصور.
- النصوص: أي نص ممكن تكتبه بلغة واحدة فقط مثل `summary: "نص"` وسيظهر في اللغتين.

**الخطوة ٤:** أنشئ مجلدًا باسم الـ slug داخل `assets/projects/` وضع فيه الصور (القسم التالي).

**الخطوة ٥:** احفظ وافتح الموقع. المشروع يظهر تلقائيًا في "أعمال مختارة"، وصفحته جاهزة على:
`project.html?p=client-name`

## ٤. صور المشاريع: الأسماء والمقاسات

ضع صور كل مشروع في: `assets/projects/<slug>/`

| اسم الملف | أين يظهر | المقاس المقترح |
|---|---|---|
| `cover.jpg` | كارت المشروع في الصفحة الرئيسية + أعلى صفحة المشروع | **1600×1000** (أو 1440×900) |
| `shot-1.jpg` | أول لقطة في المعرض (بعرض كامل) | 1600×1000 |
| `shot-2.jpg` و `shot-3.jpg` | باقي المعرض (نصف عرض) | 1600×1000 |
| `mobile.jpg` (اختياري) | قسم "على الموبايل" في صفحة المشروع. اكتب مساره في `mobile` داخل `projects.js` | 1600×1000 |

**المشاريع الحالية (الصور جاهزة — لقطات حقيقية من المواقع):**

- **Mad Watches** → `assets/projects/mad-watches/` ← `cover.jpg` و `shot-1.jpg` و `shot-2.jpg` و `shot-3.jpg` و `mobile.jpg`
- **Ahmed Ark** → `assets/projects/ahmed-ark/` ← `cover.jpg` و `shot-1.jpg` و `shot-2.jpg` و `shot-3.jpg` و `mobile.jpg`

> لو عدّلت تصميم أي موقع منهم، صوّر لقطات جديدة واستبدل الملفات بنفس الأسماء.

**نصائح لأفضل جودة:**

1. النسبة المهمة هي **16:10** (العرض ÷ الارتفاع = 1.6). الصورة تتقص من الأسفل لو كانت أطول.
2. أسهل طريقة: افتح موقع العميل في Chrome ← اضغط `F12` ← أيقونة الموبايل (Device toolbar) ← اكتب المقاس `1440 × 900` ← من قائمة النقاط الثلاث اختر **Capture screenshot**.
3. للقطات الموبايل: صوّر بمقاس الموبايل، ثم ضع اللقطة في منتصف خلفية داكنة مقاسها 1600×1000 (Canva أو Figma).
4. اضغط الصور قبل رفعها على [squoosh.app](https://squoosh.app): الهدف أقل من **400KB** لكل صورة، والصيغة JPG أو WebP.
5. لو غيّرت عدد اللقطات، عدّل قائمة `screenshots` في `projects.js` (ممكن لقطة واحدة أو عشرة).

> وأنت تعاين الموقع على جهازك، أي صورة ناقصة تظهر مكانها خلفية أنيقة عليها **اسم الملف المطلوب ومكانه بالضبط**. هذه الإرشادات **لا تظهر للعملاء** على الموقع المنشور.

## ٥. إضافة رأي عميل جديد

**الخطوة ١:** افتح `data/reviews.js`.

**الخطوة ٢:** الصق هذا القالب داخل القائمة:

```js
  {
    project: "client-name",
    name: "اسم العميل",
    role: { ar: "صاحب متجر كذا", en: "Founder, Store Name" },
    text: "نص الرأي كما كتبه العميل بالضبط."
  },
```

- `project`: نفس `slug` المشروع. الرأي يظهر في الصفحة الرئيسية **وفي صفحة المشروع**. اتركه `""` لو غير مرتبط بمشروع.
- `text`: لو العميل كتب الرأي بلغة واحدة، اكتبه هكذا `text: "..."` وسيظهر كما هو في اللغتين. لو عندك ترجمة: `text: { ar: "...", en: "..." }`.
- اختياري: صورة العميل `photo: "assets/reviews/client.jpg"` (مربعة 200×200). بدونها تظهر الحروف الأولى من اسمه.

> **انقل كلام العميل كما هو.** لا تعدّل في المعنى ولا تضف آراء غير حقيقية. الأمانة هنا جزء من قيمة علامتك.

قسم الآراء يتشكل تلقائيًا: رأي واحد يظهر بشكل كبير، وأكثر من رأي يظهرون في عمودين.

### إضافة رأي فيديو أو رسالة صوتية

مثال: رأي أحمد آرك الموجود حاليًا هو تسجيل شاشة لرسالة صوتية على واتساب.

**الخطوة ١ — جهّز الفيديو:**
- الصيغة **MP4** (لو عندك رسالة صوتية فقط، سجّل الشاشة وهي تعمل على واتساب ويب، أو حوّلها إلى MP4).
- قصّه لأهم جزء (يفضّل أقل من دقيقة)، واجعل حجمه أقل من **3MB** ليفتح بسرعة على الموبايل. يمكنك ضغطه مجانًا على [handbrake.fr](https://handbrake.fr) أو أي موقع ضغط فيديو.
- ضعه في مجلد `assets/reviews/` باسم واضح بالإنجليزي بدون مسافات، مثل `client-name-review.mp4`.

**الخطوة ٢ — صورة الغلاف (اختيارية لكن مستحسنة):**
- صورة تظهر قبل التشغيل بدل الشاشة السوداء، بنفس نسبة أبعاد الفيديو، وتضعها في نفس المجلد.
- لو لم تضع صورة، سيظهر أول إطار من الفيديو.

**الخطوة ٣ — أضف الرأي في `data/reviews.js`:**

```js
  {
    project: "client-name",
    name: { ar: "اسم العميل", en: "Client Name" },
    role: { ar: "صفته", en: "His role" },
    video: "assets/reviews/client-name-review.mp4",
    poster: "assets/reviews/client-name-review-poster.jpg"
  },
```

- يظهر تلقائيًا بشكل "رسالة صوتية حقيقية من العميل" مع زر تشغيل وشريط تقدّم، ولا يعمل تلقائيًا (الزائر هو من يضغط تشغيل).
- لو العميل كتب رأيًا أيضًا، أضف `text: "..."` في نفس الرأي وسيظهر النص فوق المشغّل.
- **لا تكتب أي نص على لسان العميل لم يقله بنفسه.**

> إطار المشغّل يأخذ شكل الفيديو تلقائيًا: عريض لتسجيلات الشاشة، وطولي لفيديوهات الموبايل.

## ٦. تعديل بياناتك ونصوص الموقع

- **اسمك:** في `js/i18n.js` تحت `brand.name` — "محمد عماد" في الجزء العربي و "Mohammed Emad" في الإنجليزي. يظهر تلقائيًا في الهيدر والفوتر وقسم "عنّي" وعناوين الصفحات.
- **اللغة الافتراضية:** في `data/site.js` غيّر `defaultLang: "ar"` إلى `"en"` لو تحب يفتح الموقع بالإنجليزي.
- **الرسالة الجاهزة لواتساب:** `whatsappMessage` في `data/site.js`.
- **رسالة زر "احجز اجتماعًا مجانيًا":** `consultMessage` في `data/site.js`.
- **رقم واتساب كما يظهر للزوار:** `whatsappDisplay` في `data/site.js` (لو غيّرت رقمك غيّر `whatsapp` و `whatsappDisplay` معًا).
- **الإيميل ويوتيوب:** `email` و `youtube` في `data/site.js`. يظهران تلقائيًا في قسم التواصل والفوتر والقائمة على الموبايل.
- **شارة "متاح لمشاريع جديدة":** `available: true` (اجعلها `false` لإخفائها).
- **أي نص في الموقع** (العنوان الرئيسي، "لماذا تحتاج موقعًا؟"، الخدمات، الاستشارة المجانية، فقرة "عنّي"...): في `js/i18n.js`. النصوص العربية في الجزء `ar` والإنجليزية في الجزء `en`.
  - قسم "لماذا تحتاج موقعًا؟" ← `why`
  - الاستشارة المجانية (القسم والصفحة) ← `consult`
  - الأتمتة (القسم في الرئيسية + صفحة automation.html) ← `auto`
  - الخدمات وباقة "موقع + أتمتة" ← `services` (الباقة تحت `bundle`)
  - "عنّي" ← `about` (المسمى الرئيسي `role`، والسطر الثانوي `lecturer` و `creator`)
- **صورتك الشخصية:** موجودة في `assets/about/me.jpg` (مقصوصة 720×900 ومضغوطة ~120KB). لتغييرها: ضع صورة جديدة بنفس الاسم، بنسبة **4:5** (مثلًا 720×900 أو 1000×1250)، وحجمها أقل من 200KB. وجهك يفضل يكون في الثلث العلوي من الصورة.

## ٨. الموقع على الإنترنت (GitHub + Vercel)

رابط موقعك: **https://mohammed-emad-portfolio.vercel.app**

- ملفات الموقع محفوظة على GitHub في المستودع `mohammed-emad-portfolio`.
- Vercel مربوط بالمستودع: **أي تعديل تحفظه على GitHub ينزل على الموقع تلقائيًا خلال دقيقة.**

### تعديل الموقع من المتصفح (بدون أي برامج)
1. افتح المستودع على GitHub وادخل على الملف اللي عايز تعدّله (مثلًا `data/projects.js`).
2. اضغط أيقونة القلم ✏️ (Edit)، عدّل، ثم اضغط **Commit changes**.
3. خلال دقيقة تقريبًا يظهر التعديل على الموقع.

### إضافة صور مشروع جديد
1. ادخل على المجلد `assets/projects/` في المستودع.
2. **Add file ← Upload files**، واسحب صور المشروع. لإنشاء مجلد جديد، اكتب اسمه في مسار الرفع (مثلًا `assets/projects/client-name/`).
3. اضغط **Commit changes**.

> لو حصلت مشكلة بعد تعديل (الصفحة فاضية مثلًا)، ارجع للنسخة السابقة من صفحة **Deployments** في Vercel: اختار آخر نسخة شغالة ← **Promote to Production**.

## ٩. صورة المعاينة على واتساب (Open Graph)

عند إرسال رابط موقعك على واتساب أو فيسبوك تظهر صورة `assets/og-image.png` مع العنوان والوصف. رابط الموقع (`mohammed-emad-portfolio.vercel.app`) مكتوب بالفعل في الصفحات.

- **لو غيّرت عنوان الموقع أو ربطت دومين خاص:** ابحث في `index.html` و `project.html` و `consultation.html` و `automation.html` و `sitemap.xml` و `robots.txt` عن `mohammed-emad-portfolio.vercel.app` واستبدله بالعنوان الجديد.
- اختبر شكل المعاينة على [opengraph.xyz](https://www.opengraph.xyz) أو [Facebook Sharing Debugger](https://developers.facebook.com/tools/debug/).

> واتساب يحتفظ بالمعاينة القديمة فترة. لو لم تتحدث، جرّب إرسال الرابط مع `?v=2` في آخره.

**ملاحظة:** صفحات المشاريع تظهر عند مشاركتها بنفس صورة وعنوان الموقع الرئيسي، لأن واتساب لا يقرأ المحتوى الذي يُنشأ تلقائيًا. داخل الصفحة نفسها يظهر كل شيء صحيحًا.
